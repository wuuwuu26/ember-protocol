## 一、编译命令

```bash
cd ue
"/c/Program Files/Epic Games/UE_5.8/Engine/Build/BatchFiles/Build.bat" \
  RobotGameEditor Win64 Development \
  -Project="C:/Users/25227/Documents/robot_game/ue/RobotGame.uproject" \
  -NoUBA -WaitMutex
```

### ⚠️ `-NoUBA` 不能省

`-NoUBA` 禁用 Unreal Build Accelerator。**在这个环境下不加它必然失败**：

```
fatal error C1083: 无法打开预编译头文件 ...SharedPCH.*.h.pch: 拒绝访问
```

UBA 会做特殊的文件操作（`SetFileInformationByHandle`），在当前环境里持续被拒，
导致 PCH 根本没生成出来，然后依赖 PCH 的编译步骤就报"拒绝访问"。
`-NoUBA` 走经典构建路径，完全正常。

代价：失去编译加速，首次全量编译约 40 秒（项目只有 3 个模块，影响不大）。

> 这是 `BuildConfiguration.cs:54` 里定义的参数：`[CommandLine("-NoUBA", Value = "false")]`。

UBT 源码 `MicrosoftPlatformSDK.cs:356` 里写死了查找顺序：


## 七、常见问题

**Q: 首次打开弹出「缺失项目设置！使用虚拟阴影贴图需要 Shader Model 6（SM6）」**
A: 已在 `Config/DefaultEngine.ini` 里修好，重启编辑器即可。

原因是 `r.Shadow.Virtual.Enable=1` 与引擎默认的 `PCD3D_SM5` 冲突。修法是
去掉 SM5、换成 SM6：

```ini
[/Script/WindowsTargetPlatform.WindowsTargetSettings]
DefaultGraphicsRHI=DefaultGraphicsRHI_DX12
-D3D12TargetedShaderFormats=PCD3D_SM5
+D3D12TargetedShaderFormats=PCD3D_SM6
```

**取舍**：SM6 要求 DX12 级硬件，而制作计划的最低配置 GTX 1660（Turing 架构）
支持 DX12 与 SM6，所以不破坏最低配置。巨构场景的阴影质量收益值得这个代价。
若要兼容更老的显卡，需退回 SM5 并关闭 `r.Shadow.Virtual.Enable`。

**Q: 编译报 PCH「拒绝访问」**
A: 忘了加 `-NoUBA`。

**Q: 报 `Could not find NetFxSDK install dir`**
A: 缺 .NET Framework SDK，见第二节。

**Q: 报 `Sdk: not found. Required version 10.0.19041.0`**
A: 缺 Windows SDK。装 VS Build Tools 的 `Microsoft.VisualStudio.Workload.VCTools` 工作负载。

**Q: 编辑器打开时报缺模块**
A: 先编译。编辑器不会自动编译 C++，需要先跑一次 Build.bat。

**Q: 日志里的中文是乱码**
A: MSVC 按系统代码页（GBK）输出，而终端按 UTF-8 读。转码即可：
```bash
grep -aE "error C" build_log.txt | iconv -f GBK -t UTF-8
```

**Q: 日志里一堆 `UbaStorageServer ... Access is denied`**
A: UBA 的文件操作被拒。加了 `-NoUBA` 就不会出现，即使出现也不影响构建结果。
