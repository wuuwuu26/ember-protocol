# 迭代报告 · 2026-10-23（第二轮）：引入高级建模操作

本轮目标：**不再用几何体拼凑，改用放样等建模操作做连续曲面**。

---

## 一、为什么"拼接"到此为止了

前几轮把方盒换成圆柱、椭球、环面之后，机体确实不再是"一摞纸箱"了，
但还有一种挥之不去的**零件感**。原因不是倒角不够，而是结构层面：

每个图元（box / cyl / ellipsoid）都是一个**封闭的、均匀的、无变化的**形体。
用它们拼一个胸腔，只能是"方块 + 球 + 圆锥"三段，段与段之间必然是接缝、
必然有曲率突变。而真实工业造型里，胸腔从腰部的方形截面，经过收腰、外扩，
到胸口的圆角梯形，是**一条连续的放样曲线** —— 它本来就不是"几个件"。

所以这一轮补的是**建模方法**，不是更多图元。

## 二、新增的六个操作（`robotlib.py`）

| 函数 | 做什么 | 关键点 |
|---|---|---|
| `loft` | 多截面放样 | 截面用**超椭圆**参数化：`n=2` 椭圆 → `n=3.5` 圆角梯形 → `n=6` 近方。放样时每层给不同的 `n`，形体就从管状平滑过渡成装甲块。截面中心可任意偏移 → 能做**弯曲**的壳体。 |
| `lathe` | 旋转体 | 一条轮廓线 `[(r,z)]` 绕轴转一圈，`r=0` 处收成极点。喷口、轮毂、球关节罩这类回转对称件，用旋转体做是唯一正确的方式。 |
| `sweep` | 沿路径扫掠 | 截面可以是任意多边形（方形边条、扁椭圆护甲条），用**平行传输**算坐标系，急转弯时截面不会突然翻面。 |
| `subdivide` | Catmull-Clark 细分 | 低模放样 + 一级细分 = 连续曲面，面数还省。 |
| `shell` | 抽壳 | 曲面 + 厚度 = 护甲板。边缘会自然形成真实板材厚度。 |
| `boolean_cut` | 布尔差集 | 散热窗、检修口、面罩槽 —— 必须真的凹进去。 |
| `bend` | 弯曲变形 | 给平直件加弧度。 |

核心是 **`_superellipse`**：`|x/a|^n + |y/b|^n = 1` 的参数化。
一个指数就能控制"从圆到方"的连续过渡，这是放样能做出现代工业造型的关键。

## 三、玩家机体：8 个部件换成放样

| 部件 | 之前 | 现在 |
|---|---|---|
| 胸腔 | 内骨架 + 腹部 + 胸腔三块 prism | **一条放样**：腰（n=5.5 近方）→ 收腰 → 胸外扩（n=2.7 椭圆）→ 肩收口，7 个截面 |
| 胸甲（左右） | 7cm 厚方板 | **放样壳**：中间鼓、上下收，同一块装甲上有连续明暗渐变 |
| 颅骨 | 圆角方盒 + 头顶椭球 | **一条放样**：下颌窄 → 颧骨最宽 → 颅顶收，6 个截面 |
| 面罩 | 贴一块黑片 | **布尔挖槽** + 目镜嵌在槽底（槽壁接住高光） |
| 肩甲 | 椭球穹顶 | **放样贝壳形**：上下曲率和前后曲率不同（椭球做不到） |
| 大腿 | 等径圆柱 | **放样**：髋部椭圆（n=2.2）→ 膝部圆角方（n=3.4），半径递减 |
| 小腿 | 等径圆柱 | **放样**，截面中心向后偏（小腿骨本来就是弯的） |
| 护膝 | 斜扣的方板 | **放样弧罩**（膝盖是腿上曲率最大处，方板必然翘边） |
| 脚 | 脚跟 prism + 脚掌方盒 + 脚趾椭球 | **一条放样靴形**：脚跟窄 → 脚掌宽 → 趾尖收 |
| 裙甲 | 两片 prism | **放样弧面**（上贴骨盆、下摆外张） |
| 腹部散热窗 | 贴一排薄片 | **布尔挖三个真槽** |

三角面：48.9k → 46.9k（LOD0，medium）。**面数还少了一点**，因为放样件替代了
"主体 + 贴片 + 接缝遮盖件"的三件套。

## 四、踩到的坑

**`loft` 的 `loc` 参数漏赋值。** 加参数时签名改对了、函数体没改，
于是 `loc=` 被接收但忽略 —— 用它的部件（脚）全部留在世界原点，
预览图里看起来像"脚从腿上掉下来了，躺在地上"。

教训：**加参数必须同时改签名和函数体**，而且要有一个用到该参数的调用点做验证
（脚是唯一用 `loc` 的地方，所以只有它炸了）。

## 五、还没做的

1. **手臂仍是圆柱 + 椭球**。它在肩甲下面，视觉权重低，但这轮没动。
   手臂该用放样做"上臂粗 → 肘部收 → 前臂方"的过渡。
2. **6 种敌人还没用放样**。上一轮刚把它们从方块换成曲面图元，
   但同样是"图元拼接"，下一步应该套用同一套放样语言。
3. **`subdivide` / `shell` 只验证了能用，没实际用上**。
   护甲板"曲面 + 抽壳"能做出真实的板材厚度和边缘内壁，值得单独做一轮。
4. 引擎内的近景截图仍然过曝（场景曝光是按全身构图标的，
   近景时英雄补光 + 太阳叠加就爆了）—— 这是检阅/特写工具的问题，不影响正常游戏。
