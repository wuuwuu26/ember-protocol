# 迭代报告 · 2026-10-23（第三轮）：缺陷排查与修复

本轮目标：**自己检查上一轮放样改造留下的问题**，不新增功能。

---

## 一、检查方法

上一轮只看了**一张 3/4 视角**的预览图，结果一半问题都没发现。
这轮补了两个工具：

| 工具 | 作用 |
|---|---|
| `inspect_chassis.py` | 同一台机体从 6 个角度各渲一张：正 / 侧 / 背 / 3/4 / 仰视 / 俯视 |
| `probe_parts.py` | 打印每个部件的包围盒（dX / dY / dZ / Z 范围），按某一维排序 |

第二个工具是关键。侧视时有个"盖住上半身的龟壳"，改了三次肩甲参数它都不变 ——
因为那根本不是肩甲，是**旧的椭球护壳 `pauldron_shell` 忘了删**。
把包围盒按 dY 排序，它排在第一位（0.45 > 放样碗的 0.40），一眼就看到了。

## 二、修掉的 7 个问题

### 1. 膝盖是断的（最严重）

大腿放样的下端停在 `knee_z + 0.03`，小腿上端从 `knee_z - 0.03` 开始 ——
中间有 **6cm 的缝**，膝盖看起来是"两截棍子对着插"。

> 修：大腿下端压到 `knee_z - 0.03`，小腿上端抬到 `knee_z + 0.04`，两者重叠。

### 2. 脚踝也是断的

脚（放样靴形）的顶部在 `zFT + 0.10`，踝关节球在 `zFT + 0.22` —— 中间空一截。

> 修：脚抬到 `zFT + 0.16`，小腿下端下探到 `ankle_z - 0.06`。

### 3. 肩甲没盖住肩关节

原来跨度只有 `xS ± 0.4·SW`（约 0.39 ~ 0.60），而**上臂在 x = 0.68**。
于是肩甲像"贴在胸口两侧的两个球"，手臂从肩甲外面凭空长出来。

> 修：跨度改成从胸腔边缘一直到上臂外侧（`xS - 0.46·SW` ~ `xS + 1.34·SW`）。

### 4. 肩甲先做成扁翼、又做成龟壳

**扁翼**：放样的 Z 轴是堆叠方向，我第一版把 5 个截面全摆在同一高度，
结果横向铺开 0.5m、竖向只有 5cm —— 一片"蝙蝠翅膀"。
→ 改成沿 Z 走"碗口 → 碗顶"的倒扣碗。

**龟壳**：碗的 Y 半径给到 `SD * 0.78`（前后直径 0.56 > 胸腔深度 0.44），
侧视时整个上半身被一个半圆罩住。
→ 收到 `SD * 0.42`（直径 0.30），并整体外移。

### 5. 旧的椭球护壳没删（"改了没反应"的真凶）

`pauldron_shell` 还留在代码里，dY=0.45、Z 1.98~2.14，正好叠在放样碗上。
肩甲参数改了三次画面都不变，就是因为它挡在外面。

> 修：删除。放样碗本身已经有"碗口→碗顶"的层次，不需要再叠一层壳。

### 6. 领口环是个帽檐

`torso_collar` 半径 `0.30 · TW` = 0.19m，比脖子粗一倍 ——
侧视时是横在头下方的一圈帽檐，和肩甲一起构成了"龟壳"的错觉。

> 修：收到 `0.17 · TW`。

### 7. 左手是三根方条，像叉子

`claw_*` 是 5×22×5cm 的直方条，斜着伸出去三根。

> 修：改成**放样锥形指**（根粗尖细、指尖收成一点）+ 指根球关节。

## 三、修复前后

| | 修复前 | 修复后 |
|---|---|---|
| 膝盖 | 6cm 断缝 | 重叠，连续 |
| 脚踝 | 空一截 | 包住踝关节 |
| 肩甲跨度 | 0.39~0.60（够不到手臂） | 0.35~0.86（罩住肩关节） |
| 肩甲侧面 | 半圆罩住上半身 | 前后 0.30 < 胸腔 0.44 |
| 领口 | 直径 0.44（帽檐） | 直径 0.25 |
| 左手 | 三根方条 | 三根锥形指 + 球关节 |

三角面：46.7k → 46.8k（基本不变）。

## 四、还没解决的

1. **手臂和肩甲之间仍有细缝**。肩甲为了不变成龟壳把 Y 半径收到了 0.30，
   而手臂根部 Y 跨度 0.28 —— 包裹余量只剩 1cm，某些角度会露黑缝。
   正解是给肩甲加一个"下沿内翻"的裙边（放样最后一层向外折），但这轮没做。
2. **背包位置偏下**，和胸腔背面之间有明显间隙。
3. **引擎内近景过曝**：材质 albedo 0.30 + 太阳 22000lux，机体在近景时白成一片。
   这是材质/布光问题，不是模型问题，需要在材质侧压 albedo 或给近景单独降曝光。
4. **腿偏细长**：大腿/小腿的半径相对躯干偏小，比例上像"竹竿腿"。
   这是设计取向，不是 bug，但和"重型机"的设定不太匹配。
