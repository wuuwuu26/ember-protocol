# 迭代报告 · 2026-10-23（第五轮）：全场景 4K 纹理

本轮目标：自己生成 4K 纹理，**所有物体都要有**。

---

## 一、先扫描：到底有多少物体没有纹理

```
M_SteelLight     211 处    M_Accent_prop     60 处
M_Steel          185 处    M_Rust            34 处
M_Copper         184 处    M_Accent_wall     34 处
M_Joint          175 处    M_Core_prop       20 处
                           M_AccentDark_prop  7 处
                           BasicShapeMaterial 5 处  ← 引擎默认材质
```

结论：**没有空槽**（每个物体都有材质），但有 **5 处用的是引擎默认的
`BasicShapeMaterial`** —— 那张灰格子图，一眼就能看出"没贴图"。

而且更根本的问题：**12 种材质里只有 2 种绑了真正的纹理**
（机体用 T_MechDetail、环境用 T_EnvDetail）。也就是说地板、墙、立柱、
集装箱、废料堆**全是同一张图**，近看就是"贴了同一张壁纸"。

---

## 二、生成 5 套 4K 纹理

新增 `tools/make_surface_set.py`，参数化生成不同表面。它复用
`make_detail_texture` 的 fbm / seam_grid / smoothstep / shift_noise，
保证噪声语言一致。

| 纹理 | 用途 | 特征 | 面板均值 | 粗糙均值 |
|---|---|---|---|---|
| `mech` | 机体、敌人 | 3×3 大板 + 分板 + 铆钉 + 稀疏刮痕 | 0.68 | 0.63 |
| `env` | 通用环境 | 更密的格 + 大块斑驳 | — | — |
| `paint` | 墙、集装箱、涂装外壳 | 2×2 大板、板面平、**掉漆斑** | 0.84 | 0.62 |
| `concrete` | 地面、基座 | 4×4 细密分格、粗颗粒、几乎无磨损 | 0.67 | 0.88 |
| `rust` | 废料、管道、旧构件 | 3×3 板 + **大量锈斑起皮** | 0.48 | 0.92 |

每套输出：
- `<name>_detail.png`（4K RGBA：R=面板遮罩 / G=粗糙度 / B=磨损 / A=高度）
- `<name>_detail_n.png`（4K 法线，从高度图环绕差分）

共 10 张 4096×4096，单张 4.5~5.7MB。

**参数化的关键**：所有"按像素写"的参数都乘 `S = SIZE/1024`。
4K 下缝宽必须从 16px 变 64px，否则在 1.2m 的 UV 尺度上只有 4.7mm，远看消失。

## 三、按材质类型分配

`make_surface_materials.py` 里加了一张映射表：

```python
M_Steel      → 混凝土（地面/基座为主）
M_SteelLight → 涂装钢板（结构件）
M_Joint      → 锈蚀
M_Copper     → 锈蚀
M_Rust       → 锈蚀
M_Accent*    → 涂装
M_Core       → 涂装（发光件 DetailAmount=0，纹理不参与）
Characters/* → 机体纹理
```

长名优先匹配（`M_AccentDark` 不能被 `M_Accent` 抢先）。

顺带用 `fix_default_mat.py` 把 5 处 `BasicShapeMaterial` 换成项目材质
（低矮大面积的当地面用混凝土钢，其余用涂装钢）。

## 四、找到了"机体发黑"的真因

改完纹理后发现机体还是黑 —— 但地面很亮，而地面的 albedo（0.105）
比机体（0.30）**更低**。这不合理，除非材质模型有问题。

查下来是**金属度**：

```
M_SteelLight  metallic 0.42
M_Steel       metallic 0.30
```

涂装装甲板的本质是"漆面"，金属度应该接近 0.1。给到 0.3~0.42 之后，
材质几乎只靠**反射环境** —— 而这个场景是夜景、天空很暗，
于是机体永远是黑的，贴图细节完全看不见。

> 改成 0.10 / 0.16 之后，机体立刻亮了，板缝和铆钉都能看清。

这解释了"为什么改了纹理还是看不到纹理"——**一半原因是纹理坏了（32×32），
另一半是材质根本不给漫反射的机会**。

## 六、遗留

1. **画面整体偏橙**。纹理已经正常，但色调被雾和低角度暖光拉成橙红。
   下一步应该单独调一轮：雾的 directional inscattering 色、
   太阳色温（5200K 偏低，可以试 6500K）、PPV 的 ColorGain。
2. `env` 这套纹理的缝宽参数还是 1024 基准时代的，没有按 4K 重新核对
   （它现在和 concrete 有些重复，下一轮可以考虑合并）。
3. 发光件（M_Core）没有专用纹理 —— 目前 `DetailAmount=0` 直接跳过，
   对发光条来说是对的，但如果以后要做"发光面板有内部纹路"需要补一张。
